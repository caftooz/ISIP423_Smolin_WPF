## Выводы о проведённом тестировании

Все автоматизированные unit-тесты были пройдены успешно.

**Причины успешного выполнения тестов авторизации:**
- Модуль AuthService корректно проверяет логин и пароль в базе данных
- Обработаны граничные случаи: пустые строки и null-значения возвращают false

**Причины успешного выполнения тестов регистрации:**
- Модуль RegistrationService выполняет все необходимые проверки перед добавлением пользователя
- Корректно обрабатываются пустые/null поля, несовпадающие пароли
- Проверяется уникальность логина и email в базе данных

**Причины успешного выполнения тестов капчи:**
- CaptchaService генерирует строки фиксированной длины из безопасного набора символов (исключены похожие: 0/O, 1/l/I)
- Валидация чувствительна к регистру
- Счётчик неудачных попыток корректно срабатывает после 3 ошибок
- Регенерация капчи инвалидирует предыдущий код
